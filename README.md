Cloud Hopper

What is it?
Cloud Hopper is a game that you have to keep going up without falling, if you fall you die.

Special things,
There is power-ups to make you go high, and there are also some entities that kills you.

Controls, 
The controls are, A - D or left and right arrow keys.
